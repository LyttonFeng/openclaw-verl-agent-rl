Committee-Reward RL：qwen3.5-4b 能否在"委员会"口径上净胜 base？

Agentic meeting-analysis (Val3: advisory / gov / tech) · temp=0.3 RUNS=3 · 9-pair 异构委员会 · 2026-06-15

一句话结论：能（有限度）。 committee-reward 把 qwen3.5-4b 在委员会口径上训到胜 base（gov）、advisory/tech 持平 —— 而这个真实增益对规则型 automated grader 完全隐形、甚至反向。但只有大比分（w3 gov 9:0）真可信，6:1~8:1 跨 eval 会抖动。 AUTO_W 和 deliberation 都不是质量杠杆（deliberation 干净重跑证明无可见质量收益 → 默认关闭；对 reward 方差的作用未测，有降再开回来）；真正缺的是"能制造可辨差异"的更难任务。

发现 2 — w2 悖论：automated 最高 = 委员会最弱（解耦甚至反向）

w2：automated 全场最高（gov .93/.86，MEETING 81.3%，唯一超 base）→ 委员会最弱（gov 平 4:4，全平）。
w3：automated 偏低（74.7%）→ 委员会最强（gov 9:0）。
刷 automated 产出的是"规则眼里最好、委员会眼里没更好"的报告 —— 对真实质量是反效果。

committee verdict 跨 eval 会抖：同一个 w5 adapter 判同一 base，flake 那次 gov 8:1 (p=.039 显著)、clean 这次 gov 6:1 (p=.125 不显著)。6:1/7:1/8:1 都会跨次跳 —— 只有大比分（w3 9:0 p=.004）可信。

发现 4 — AUTO_W 不是杠杆；tech 有空间但未稳定动起来

  • AUTO_W：受控组 w3/w4/w5/w6（同数据+init）里 gov 胜在 0.0→0.7 全程成立 → AUTO_W 非关键。早先 temp=0 "w3 最差" 是 base 非确定性 confound，锚定 base 后 w3 advisory 反而 6:2 偏 lora（佐证 canonical-base 协议的必要性）。
  • tech：base ~0.72 有约 28% 空间，不是天花板。RL 把覆盖抬上去（owners 0.17→0.67），但准确率随机起伏（w4 attribution 0.50→0.25；w5-clean 守住 0.50；w5-flake 0.17 是失败run假象）—— 没有哪个设置稳定地"覆盖+准确双赢"。净委员会平 = 覆盖 vs grounding 冲突 + tie 区不可辨。要真动 tech 得换更难任务造可辨差异。

方法学要点

  • canonical base 锚定：temp=0 在不同 eval 调用间会产出不同的确定性轨迹（agentic 多轮非确定性）→ base 不唯一是真 confound。固定一份 base@0.3，所有 lora 对同一 base 判。
  • temp=0.3 为的是 eval 有效性而非提质：同一次调用内 3 run md5 互异（实测每个变体 3/3），才凑得出 9 个真对、看得到质量分布。
  • 9-pair 委员会：ds-v4-flash / qwen3-max / MiniMax-M3 异构面板 × 双序一致性（翻序即判平，去位置偏置）× 分歧组 deliberation × sign-test；base-vs-base null 校准 ≈ 全平。
  • 训练链路：vLLM 0.22 在 qwen3.5 上 online-LoRA 是 no-op → 训练与推理都走 transformers+PEFT shim；reward = RULER 式相对委员会 listwise，blend automated + llm_rubric + base-ref（放法B 仅校准）。

结论与下一步

无单一"最佳"配置：w5-clean / w4 / w6 约等价（gov 偏胜、advisory/tech 平）。下一轮从任一 committee 训练的 adapter 续训即可（默认 w6）；deliberation 默认关闭 —— 质量上无实测收益；对 reward 方差的作用未测，若实测有降再开回来。

下一步候选：① 补跑干净 w5（已做，反而证明 deliberation 无质量增益）；② 真正要进步：换 base 会明显做错的更难任务，制造"人和委员会都看得出"的可辨差异（advisory/tech 现在卡在不可辨 tie 区）；③ 把 automated 降到软门(floor/gate)而非 co-driver；④ 关键节点人工抽检（抓明显注水/幻觉，不仲裁细微 tie）。
