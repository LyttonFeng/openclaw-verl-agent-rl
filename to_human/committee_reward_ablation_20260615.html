Committee-Reward RL：qwen3.5-4b 能否在"委员会"口径上净胜 base？

Agentic meeting-analysis (Val3: advisory / gov / tech) · temp=0.3 RUNS=3 · 9-pair 异构委员会 · 2026-06-15

一句话结论：能。 committee-reward 把 qwen3.5-4b 训到委员会口径显著胜 base（gov）、advisory 不输、tech 持平 —— 而这个真实增益对规则型 automated grader 完全隐形、甚至反向。决定性杠杆是判官 deliberation，不是 AUTO_W 混合权重。

发现 2 — w2 悖论：automated 最高 = 委员会最弱（解耦甚至反向）

w2：automated 全场最高（gov .93/.86，MEETING 81.3%，唯一超 base）→ 委员会最弱（gov 平 4:4，全平）。
w3：automated 偏低（74.7%）→ 委员会最强（gov 9:0）。
刷 automated 产出的是"规则眼里最好、委员会眼里没更好"的报告 —— 对真实质量是反效果。

发现 3 — deliberation 是真正的稳定器（w6 vs w5，只差 delib）

deliberation = 仅在判官分歧 >0.25 的组追加一轮"互看后重评"，削掉离群误判，给 GRPO 更稳的相对 advantage。w6 训练全程触发 8 次（全在 advisory）。它阻止了委员会奖励"用 grounding/准确率换覆盖"。

发现 4 — AUTO_W 不是杠杆；tech 有空间但只有 w6 动对方向

  • AUTO_W：受控组 w3/w4/w5/w6（同数据+init）里 gov 胜在 0.0→0.7 全程成立 → AUTO_W 非关键。早先 temp=0 "w3 最差" 是 base 非确定性 confound，锚定 base 后 w3 advisory 反而 6:2 偏 lora（佐证 canonical-base 协议的必要性）。
  • tech：base ~0.72 有约 28% 空间，不是天花板。RL 都把覆盖抬上去（owners 0.17→0.67），但除 w6 外都用准确率换覆盖（w4 attribution 0.50→0.25、w5→0.17）。只有 w6 覆盖+准确双不输。净委员会平 = 覆盖 vs grounding 冲突在 tech 重演。

方法学要点

  • canonical base 锚定：temp=0 在不同 eval 调用间会产出不同的确定性轨迹（agentic 多轮非确定性）→ base 不唯一是真 confound。固定一份 base@0.3，所有 lora 对同一 base 判。
  • temp=0.3 为的是 eval 有效性而非提质：同一次调用内 3 run md5 互异（实测每个变体 3/3），才凑得出 9 个真对、看得到质量分布。
  • 9-pair 委员会：ds-v4-flash / qwen3-max / MiniMax-M3 异构面板 × 双序一致性（翻序即判平，去位置偏置）× 分歧组 deliberation × sign-test；base-vs-base null 校准 ≈ 全平。
  • 训练链路：vLLM 0.22 在 qwen3.5 上 online-LoRA 是 no-op → 训练与推理都走 transformers+PEFT shim；reward = RULER 式相对委员会 listwise，blend automated + llm_rubric + base-ref（放法B 仅校准）。

结论与下一步

最佳模型 = w6（AUTO_W=0 + deliberation）：gov 显著赢 + advisory 干净 6:2 + tech 准确率不塌 + automated≈base。

下一步候选：① 补跑一份干净 w5 advisory，彻底坐实 deliberation 增益；② 从 w6 继续 on-policy 训练，攻 advisory 至显著；③ 换 base 会做错的更难 tech 任务，制造 headroom 让 tech 真动；④ 把 automated 降到软门(floor/gate)而非 co-driver。
